练习靶场

靶场 说明
DVWA 经典的 Web 漏洞靶场，适合入门
Vulhub 基于 Docker 的漏洞复现环境
HackTheBox 在线渗透挑战平台

常用工具

注意：所有练习请在法律允许的范围内，对授权目标进行。

学习路线建议

  1. 计算机网络与 HTTP 协议基础
  2. 常见 Web 漏洞原理（SQLi、XSS、SSRF、RCE 等）
  3. 漏洞靶场实操（DVWA → Vulhub）
  4. 工具链熟练（Burp Suite、nmap、sqlmap）
  5. 实战：CTF 比赛 / 众测平台
